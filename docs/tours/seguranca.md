# Tour de Segurança

Abra a aba **Segurança** para iniciar. O artigo de referência é [Segurança](../ajuda/seguranca.md).

| Passo | Alvo | Orientação |
| --- | --- | --- |
| Confirmar acesso | `security-confirm` | Se esta etapa aparecer, informe sua senha atual para abrir as configurações de segurança. |
| Alterar senha | `security-password` | Preencha a senha atual e a nova senha. Confirme a nova senha antes de salvar. |
| Verificação em duas etapas | `security-two-factor` | Clique em **Ativar**, leia o QR code e digite o código do autenticador. Use **Desativar** para cancelar. |
| Chaves de acesso | `security-passkeys` | Gerencie suas chaves de acesso ou adicione uma em um navegador compatível. |
