# Tour de Segurança

Abra a aba **Segurança** para iniciar. O artigo de referência é [Segurança](../ajuda/seguranca.html).

| Passo | Alvo | Orientação |
| --- | --- | --- |
| Confirmar acesso | `security-confirm` | Se esta etapa aparecer, informe sua senha atual para abrir as configurações de segurança. |
| Alterar senha | `security-password` | Preencha a senha atual e a nova senha. Confirme a nova senha antes de salvar. Use o ícone de olho de cada campo para mostrar ou ocultar a senha. O tutorial não revela os caracteres. |
| Verificação em duas etapas | `security-two-factor` | Clique em **Ativar**, leia o QR code e digite o código do autenticador. Use **Desativar** para cancelar. |
| Chaves de acesso | `security-passkeys` | Gerencie suas chaves de acesso ou adicione uma em um navegador compatível. |

Revise os passos conforme as permissões pessoais do cargo; não demonstre uma operação que o usuário atual não está autorizado a executar.

Executor disponível pelo botão **Tutorial desta tela** na barra superior. Configuração em `resources/js/app/guidance.ts`. Revisar alvos em desktop e mobile a cada alteração.
