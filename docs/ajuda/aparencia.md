## Abrir as preferências

Abra o menu do perfil e acesse **Aparência**. É necessária a permissão de visualizar aparência. Escolha a preferência disponível na tela. As preferências locais do navegador não são mudanças nos dados de negócio.

## Tutorial

Use **Tutorial desta tela** na barra superior para localizar as configurações. Feche com Esc ou Concluir.
